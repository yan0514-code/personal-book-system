# personal-book-system
个性化图书推荐系统
基于Java实现的控制台图书推荐项目，采用文本文件持久化存储用户、图书数据。
## 项目功能
1. 用户数据加载与保存，支持默认用户自动创建
2. 添加已读图书，记录用户阅读记录
3. 查看个人已读图书列表
4. 基于图书标签相似度的个性化图书推荐
5. 浏览系统内全部图书信息
6. 输入异常捕获，提升程序健壮性
## 文件说明
- Main.java：程序入口主类，控制台菜单交互、接收用户输入，调度所有功能
- Book.java：图书实体类，存储图书ID、书名、作者、标签信息
- User.java：用户实体类，存储用户ID、用户名、已读图书ID列表
- RecommendationSystem.java：系统核心类，包含数据读写、推荐算法逻辑
- books.txt：图书信息持久化存储文件
- users.txt：用户信息持久化存储文件
## 运行方式
编译并运行 Main.java，在控制台根据菜单提示输入数字进行操作。
